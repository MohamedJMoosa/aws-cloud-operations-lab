# Incident 01 - High CPU Utilization

## Incident
High CPU utilization detected on the EC2 server.

## Detection
CloudWatch alarm detected CPU utilization above 70%.

## Investigation
1. Checked the CloudWatch CPUUtilization metric.
2. Connected to the EC2 instance via SSH.
3. Checked server CPU usage.

## Root Cause
High CPU load generated by a stress test.

## Resolution
Stopped the stress test and verified CPU utilization returned to normal.

## Prevention
CloudWatch alarm and SNS email notifications are configured to detect future high CPU utilization.
